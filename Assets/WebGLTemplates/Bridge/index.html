Browser Security Notice

Web browsers (Chrome, Edge, Firefox, Safari) prevent WebAssembly games from loading directly from raw file:/// paths due to cross-origin security policies.

To play or test this build:

1. Double-click Run_Game.bat in this folder (no installation required!).

2. Or share online by uploading this folder directly to itch.io, Netlify, or GitHub Pages.
